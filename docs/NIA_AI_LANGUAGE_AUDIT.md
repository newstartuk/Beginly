# Nia "AI" Language Audit

**Date:** 2026-08-11
**Reason:** Nia currently runs on deterministic, rule-based logic (`lib/platform/nia.ts` — keyword/string matching, no LLM call). Several places in the product described her as "AI," "AI-powered," or "AI-assisted," which overstates the current implementation. This audit finds and corrects those claims.

## Scope

Searched all `.ts`/`.tsx` source under the app for the strings "AI", "LLM", "GPT", "artificial intelligence", and "machine learning" within two lines of any mention of "Nia". Internal strategy docs (`docs/*.md`) were spot-checked but not edited — see **Not in scope** below.

## Why this matters

- `app/terms-of-service/page.tsx` made an affirmative legal claim — "Nia's responses are generated by AI" — that was factually false given the current implementation. This is the highest-risk item found.
- `app/privacy-policy/page.tsx` referenced GDPR Article 22 ("automated decision-making") while also calling the same feature "AI," which is confusing since Nia *is* automated (rule-based) but not AI in the ML sense.
- Marketing and onboarding copy set an inaccurate user expectation (e.g. hallucination-prone LLM behavior) for a system that is actually deterministic and cannot go off-script.

## Changes made

All edits replace "AI" / "AI-powered" / "AI-assisted" with accurate, neutral terms — mainly "automated" — without changing tone or removing the human-facing disclaimers.

## Suggested next steps

1. **Ship these copy fixes** — they're low-risk, string-only changes.
2. **Decide on `AI_PROVIDER` activation plan** — if/when Nia actually gets an LLM backend, the admin labels and `docs/activation/AI_NIA_ACTIVATION.md` become accurate; until then they're fine as internal toggles.
3. **Consider renaming `aiConsent` → `personalisationConsent`** end-to-end (type, DB mapping comment, policy, eval fixtures) in a dedicated small PR, since the field never actually gated AI usage — it gates profile personalisation.
4. **Reconcile `BEGINLY_STRATEGIC_COMPENDIUM.md`** if it's used as onboarding material for new hires/investors, so it doesn't imply Nia is already LLM-backed today.
